## ✨ ویژگی‌های کلیدی

### 🛒 فروشگاه و محصولات
- **کاتالوگ محصولات** — لیست محصولات صفحه‌بندی‌شده با جستجو، فیلتر بر اساس دسته‌بندی، برند و بازه قیمت، و مرتب‌سازی چند فیلدی (قیمت، تاریخ، عنوان)
- **صفحه جزئیات محصول** — اطلاعات کامل محصول با گالری تصاویر، زوم، امتیاز ستاره‌ای و نظرات تأیید‌شده مشتریان
- **سبد خرید** — سبد خرید مبتنی بر Session برای مهمانان با همگام‌سازی خودکار دیتابیسی برای کاربران وارد‌شده (از طریق سیگنال‌های جنگو هنگام ورود/خروج)
- **لیست علاقه‌مندی‌ها** — افزودن/حذف محصولات با عملکرد Toggle (با AJAX)
- **سیستم کوپن و تخفیف** — کوپن‌های تخفیف درصدی با محدودیت استفاده، تاریخ انقضا و ردیابی مصرف هر کاربر
- **محاسبه مالیات** — محاسبه خودکار ۱۰% مالیات با محاسبات دقیق `Decimal`
- **تولید داده آزمایشی** — دستور مدیریتی (`generate_fake_products`) برای ساخت داده‌های تستی واقع‌گرایانه با تصاویر توسط Faker

### 💳 پرداخت و تسویه
- **یکپارچه‌سازی با Stripe Checkout** — انتقال امن به صفحه پرداخت Stripe با مدیریت کامل Session
- **Stripe Webhook** — تأیید سمت سرور رویداد `checkout.session.completed` با اعتبارسنجی امضا
- **چرخه عمر سفارش** — مدیریت سفارش سه‌مرحله‌ای: در انتظار → موفق / ناموفق، با پاکسازی خودکار سبد خرید پس از پرداخت
- **لغو سفارش** — به‌روزرسانی خودکار وضعیت سفارش به "ناموفق" هنگام لغو توسط کاربر در Stripe

### 👤 احراز هویت و کاربران
- **مدل کاربری سفارشی** — احراز هویت مبتنی بر ایمیل (بدون نام کاربری)، با نقش‌های `customer`، `admin` و `superuser`
- **تأیید ایمیل** — توکن‌های امضاشده با مهلت زمانی (Django Signer) با قابلیت تنظیم مدت اعتبار (پیش‌فرض: ۲۴ ساعت)
- **بازیابی رمز عبور** — جریان کامل بازیابی رمز از طریق ایمیل با تمپلیت‌های HTML سفارشی
- **تجدید Session** — کلید Session پس از هر ورود موفق بازسازی می‌شود (جلوگیری از Session Fixation)
- **ضد شمارش ایمیل** — پیام‌های خطای عمدتاً مبهم در ثبت‌نام برای جلوگیری از کشف ایمیل

### 📊 داشبورد ادمین
- **داشبورد تحلیلی** — داشبورد حرفه‌ای با کارت‌های KPI (درآمد، سفارشات، مشتریان، محصولات)، نمودار درآمد ماهانه Chart.js (ترکیبی bar + line) و نمودار دونات وضعیت سفارشات
- **مدیریت محصولات** — CRUD کامل با آپلود تصویر، تخصیص چند دسته‌بندی، انتخاب برند و وضعیت منتشر/پیش‌نویس
- **ساخت سریع** — ساخت آنی برند و دسته‌بندی جدید با AJAX بدون ترک صفحه فرم محصول
- **مدیریت سفارشات** — مشاهده تمام سفارشات با جستجو، فیلتر وضعیت، مرتب‌سازی و نمای جزئیات سفارش/فاکتور
- **مدیریت مشتریان** — لیست کامل مشتریان با فیلتر نقش/وضعیت، تغییر آنی وضعیت فعال/تأییدشده با AJAX، ویرایش پروفایل و مدیریت سطح دسترسی
- **مدیریت کوپن‌ها** — CRUD کامل کوپن‌های تخفیف با کد، درصد، محدودیت مصرف، تاریخ انقضا و نشانگرهای وضعیت زنده (فعال/منقضی/حد مجاز)
- **مدیریت نظرات** — لیست نظرات با فیلتر وضعیت (در انتظار/تأیید/رد)، جستجو و ویرایش
- **خروجی CSV** — دانلود یک‌کلیکه CSV برای سفارشات، مشتریان، محصولات و کوپن‌ها از هر صفحه لیست و داشبورد
- **تنظیمات پروفایل** — ویرایش اطلاعات شخصی، تصویر پروفایل و تغییر رمز عبور

### 👥 داشبورد مشتری
- **داشبورد شخصی** — نمای کلی با کارت‌های KPI (مجموع خرید، سفارشات، علاقه‌مندی‌ها، نظرات)، نمودار وضعیت سفارشات و لینک‌های سریع
- **مدیریت پروفایل** — ویرایش اطلاعات شخصی، تصویر پروفایل و رمز عبور
- **دفترچه آدرس** — CRUD کامل آدرس‌های ارسال با مرتب‌سازی
- **تاریخچه سفارشات** — مشاهده سفارشات گذشته با جستجو، فیلتر وضعیت، مرتب‌سازی و فاکتور
- **پیش‌نمایش علاقه‌مندی‌ها** — آخرین آیتم‌های علاقه‌مندی در داشبورد با لینک به صفحه محصول
- **مدیریت علاقه‌مندی‌ها** — مرور و حذف آیتم‌ها با جستجو و صفحه‌بندی
- **نظرات من** — مشاهده تمام نظرات ارسالی و وضعیت تأیید آن‌ها

### 🛡️ ویژگی‌های امنیتی
- **محدودیت نرخ درخواست** — محدودیت IP-based روی ورود (۱۰/دقیقه)، ثبت‌نام (۵/دقیقه)، ارسال مجدد ایمیل (۳/دقیقه) و اعتبارسنجی کوپن (۱۰/دقیقه)
- **لیست سفید Order-by** — اعتبارسنجی تمام فیلدهای قابل مرتب‌سازی در برابر لیست سفید صریح
- **حفاظت CSRF** — میان‌افزار CSRF جنگو روی تمام فرم‌ها
- **حفاظت XSS** — میان‌افزار امنیتی جنگو
- **توکن‌های امضاشده** — تأیید ایمیل با امضای رمزنگاری جنگو
- **اعتبارسنجی ورودی** — اعتبارسنجی شماره تلفن، قدرت رمز عبور و ورودی فرم‌ها
- **متغیرهای محیطی** — مدیریت تمام اطلاعات حساس از طریق فایل `.env`

### 🔧 DevOps و تست‌ها
- **Docker Compose** — سه سرویس: اپلیکیشن جنگو، PostgreSQL 15 و smtp4dev
- **۸۵ تست خودکار** — پوشش تست جامع در ۶ اپلیکیشن (مدل‌ها، فرم‌ها، ویوها، سیگنال‌ها، توکن‌ها)

- **لاگ‌گیری ساختاریافته** — لاگ‌گیری در سطح ماژول با پیکربندی per-app
- **Debug Toolbar** — Django Debug Toolbar برای پروفایلینگ در توسعه

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- **Docker** (پیشنهادی) یا **Python 3.10+**
- **حساب Stripe** (برای تست پرداخت — [کلیدهای تستی](https://dashboard.stripe.com/test/apikeys))

### کلون پروژه
```bash
git clone https://github.com/alikavianifar/Django-Ecommerce.git
cd Django-Ecommerce
```

### 🐳 روش ۱: داکر (پیشنهادی)
```bash
# ۱. کپی فایل محیطی و پیکربندی
cp envs/dev/django/.env.example envs/dev/django/.env
# فایل .env را ویرایش کنید — کلیدهای Stripe تستی خود را وارد کنید

# ۲. ساخت و اجرای تمام سرویس‌ها
docker-compose up --build

# ۳. اجرای migration ها
docker-compose exec backend sh -c "python manage.py migrate"

# ۴. ساخت سوپریوزر (حساب ادمین)
docker-compose exec backend sh -c "python manage.py createsuperuser"

# ۵. (اختیاری) تولید ۵۰ محصول نمونه با تصاویر
docker-compose exec backend sh -c "python manage.py generate_fake_products --count 50 --use-static-images"
```

| سرویس | آدرس |
|-------|------|
| **اپلیکیشن وب** | http://localhost:8000 |
| **smtp4dev (رابط ایمیل)** | http://localhost:5000 |
| **پنل مدیریت جنگو** | http://localhost:8000/admin/ |

### 🖥️ روش ۲: توسعه محلی (بدون داکر)
```bash
# ۱. ساخت و فعال‌سازی محیط مجازی
python -m venv venv
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows

# ۲. نصب وابستگی‌ها
pip install -r requirements.txt

# ۳. تنظیم متغیرهای محیطی
cp envs/dev/django/.env.example envs/dev/django/.env

# ۴. اجرای migration ها
cd core
python manage.py migrate

# ۵. ساخت سوپریوزر
python manage.py createsuperuser

# ۶. اجرای سرور
python manage.py runserver

# ۷. (اختیاری) تولید محصولات نمونه
python manage.py generate_fake_products --count 50 --use-static-images
```

## 🔒 شیوه‌های امنیتی

| شیوه | پیاده‌سازی |
|------|-----------|
| **بدون اطلاعات حساس Hardcoded** | تمام مقادیر حساس از `.env` خوانده می‌شوند |
| **فایل `.env` از Git حذف** | `.gitignore` فایل‌های `*.env` را مسدود می‌کند |
| **Rate Limiting** | `django-ratelimit` روی ورود، ثبت‌نام، ارسال مجدد ایمیل و کوپن |
| **حفاظت CSRF** | میان‌افزار `CsrfViewMiddleware` روی تمام فرم‌ها |
| **جلوگیری از SQL Injection** | فیلدهای order-by با لیست سفید صریح اعتبارسنجی می‌شوند |
| **Session Fixation** | کلید Session پس از هر ورود موفق بازسازی می‌شود |
| **ضد شمارش ایمیل** | پیام‌های خطای مبهم در ثبت‌نام |
| **امنیت Webhook** | امضای Payload قبل از پردازش هر رویداد Stripe تأیید می‌شود |
| **اعتبارسنجی رمز عبور** | ۴ اعتبارسنج داخلی جنگو |
| **DEBUG پیش‌فرض خاموش** | `DEBUG=False` پیش‌فرض — باید صریحاً فعال شود |

## 🌐 آدرس‌ها و Endpointها

### صفحات عمومی
| متد | آدرس | توضیح |
|-----|------|-------|
| GET | `/` | صفحه اصلی |
| GET | `/shop/products/` | لیست محصولات |
| GET | `/shop/product-details/<slug>/` | جزئیات محصول |

### احراز هویت
| متد | آدرس | توضیح |
|-----|------|-------|
| GET/POST | `/accounts/login/` | ورود (محدودیت: ۱۰/دقیقه) |
| GET/POST | `/accounts/register/` | ثبت‌نام (محدودیت: ۵/دقیقه) |
| GET | `/accounts/verify-email/<token>/` | تأیید ایمیل |
| GET/POST | `/accounts/password/reset/` | بازیابی رمز عبور |

### سبد خرید (AJAX)
| متد | آدرس | توضیح |
|-----|------|-------|
| POST | `/cart/session/add-product/` | افزودن محصول |
| POST | `/cart/session/remove-product/` | حذف محصول |
| POST | `/cart/session/update-product-quantity/` | بروزرسانی تعداد |
| GET | `/cart/summary/` | خلاصه سبد خرید |
