Project Overview

Comprehensive E-Commerce Architecture

A production-ready, full-featured web application built with Django 4.2 LTS. This platform delivers a complete shopping experience from product browsing and cart management to Stripe payment processing with webhook verification, backed by robust administration and security protocols.

Robust Security

Built-in CSRF/XSS protection, comprehensive rate limiting, strict SQL injection safeguards, and email-verified user accounts ensure enterprise-level safety.

Data Integrity

Powered by PostgreSQL 15. Complex relational schemas handle everything from product catalogs to hierarchical order processing seamlessly.

Seamless Payments

Deep Stripe checkout integration utilizing webhook listeners. Payments are asynchronously verified and order lifecycles are fully automated.

DevOps Ready

Fully Dockerized environment backed by an automated CI/CD pipeline executing over 85 unit tests on every push via GitHub Actions.

Platform Capabilities

Comprehensive Feature Breakdown

A detailed look at the core modules that power this e-commerce ecosystem, based on the project's technical specifications.

Authentication & Users

Custom User Model

Email-based authentication with distinct roles (Customer, Admin, Superuser), completely bypassing Django's default username requirement.

Email Verification

Time-limited signed tokens (via Django Signer) are emailed to users upon registration. Accounts remain restricted until verified.

Password Management

Complete email-based password recovery flow with custom HTML templates, plus secure in-dashboard password updates.

Session Cycling

Session keys are automatically regenerated on login to prevent session fixation attacks, enhancing user security.

Shopping & Checkout

Advanced Product Catalog

Paginated listings with multi-field sorting, category/brand filters. Detail pages include GLightbox galleries, Drift.js zoom, and star ratings.

Session-Synced Cart

Guest users utilize a session-based cart. Upon authentication, Django signals automatically synchronize session items with the database cart.

Coupons & Tax

Percentage-based discount coupons with usage limits and expiry dates. Automatic 10% tax is calculated using precise Decimal arithmetic.

Stripe Checkout & Webhooks

Secure redirect to Stripe Checkout. Server-side webhook verification handles payment success and automates order status updates.

Dashboards & Management

Admin Analytics Console

Professional dashboard with KPI cards and Chart.js visualizations (revenue bar/line combos and order status doughnut charts).

Full CRUD Management

Complete admin interfaces for managing Products, Categories, Brands, Orders, Customers, Coupons, and moderating Reviews.

Customer Dashboard

Personal hub featuring total spent metrics, order tracking timelines, downloadable invoices, multi-address book, and wishlist management.

CSV Export Engine

One-click data export capabilities allowing admins to download Orders, Customers, Products, and Contact Messages directly to CSV.

Security & DevOps

Advanced Security

IP-based Rate Limiting (login, registration, coupons), explicit Order-by whitelists (SQLi prevention), and Anti-Enumeration techniques.

Environment Variables

All sensitive data and Stripe keys are strictly managed via decoupled `.env` files, keeping the public repository completely clean.

Automated Testing (CI)

Over 85 unit tests covering models, forms, views, and signals. Executed automatically on GitHub Actions for every pull request.

Docker Containerisation

A three-service Docker Compose architecture orchestrating the Django app, PostgreSQL 15, and smtp4dev for seamless deployment.
